# Contributing

Please describe the problem, the installed app version, and reproducible steps. Use fabricated examples instead of account exports or real credentials. Run `npm test` and `npm run audit` before opening a pull request. UI changes should also be checked with `npm run smoke` on Windows.

Do not commit login profiles, generated archives, workstation paths or screenshots containing personal information. Keep existing third-party license notices. Open an issue before changing backend endpoints or the release manifest contract.
